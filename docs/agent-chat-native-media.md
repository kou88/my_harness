# AIチャットのネイティブ画像・動画入力

アプリは選択モデルの公開`inputModalities`だけを入力欄に反映する。画像は最大4枚、元動画はMP4を最大1本・32 MiBまで。iPhoneが選択したMOVなど未対応形式は明示エラーにし、JPEGフレームへ変換しない。画像は従来どおりJPEGへ正規化し、1枚8 MiBまで。添付合計はAPI側で64 MiBまで。

動画は元MP4を1件の添付としてAPIへアップロードする。履歴では動画として表示し、画像プレビューへの誤読込を避ける。モデル切替時も現在の添付に対応する公開能力を確認する。公開能力はモデル本来の仕様だけではなく、PCのmmproj・vision tower・backend動画形式・デコーダが揃い、実機テストで確認できた範囲とする。

この変更のSwiftドメインテストとiOS Simulator向け全ターゲットbuildは通過。実動画認識とOpen WebUIの表示はPC-02のPCIe `BadTLP`と`ffprobe`不足により未確認であり、現時点のPC-02カタログは動画入力を有効にしない。
