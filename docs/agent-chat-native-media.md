# AIチャットのネイティブ画像・動画入力

アプリは選択モデルの公開`inputModalities`だけを入力欄に反映する。画像は最大4枚、動画はMP4を最大1本・32 MiBまで。iPhoneが選択したMOVなどは端末内のAVFoundationでH.264/AACのMP4へ変換してから送る。既に有効なMP4で32 MiB以下なら再エンコードしない。変換できない動画、変換後も32 MiBを超える動画は明示エラーにし、JPEGフレームへ変換しない。画像は従来どおりJPEGへ正規化し、1枚8 MiBまで。添付合計はAPI側で64 MiBまで。

動画はMP4を1件の添付としてAPIへアップロードする。変換前の一時ファイルと変換後の一時ファイルは処理後に削除する。履歴では動画として表示し、画像プレビューへの誤読込を避ける。モデル切替時も現在の添付に対応する公開能力を確認する。公開能力はモデル本来の仕様だけではなく、PCのmmproj・vision tower・backend動画形式・デコーダが揃い、実機テストで確認できた範囲とする。

2026-09-27のiPhone 17 Pro / iOS 26.4 Simulatorで、写真ピッカーからH.264 MOV（緑→黄）とHEVC MOV（シアン→マゼンタ）を選択し、いずれも`動画.mp4`として本文付きで送信した。UD-Q8の回答が各動画の色変化と一致し、変換・アップロード・ネイティブ動画認識までE2E確認した。SwiftドメインテストとSimulator buildも通過。実際のiPhoneで撮影した長尺・HDR動画と、TestFlight実機インストールは別途未確認。PC-02の実行時capabilityとバックエンドの検証結果は`cmp170hx_ubuntu/docs/records/2026-09-27-native-multimodal-status.md`に記録する。
