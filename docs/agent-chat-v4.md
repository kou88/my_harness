## チャット内の操作

- 配色はアプリ共通。AI画面・設定シートのダーク固定を撤去し、入力欄・ドロワー・コード・送信ボタンも同時に切り替わる。
- 入力欄のbrainアイコンからreasoning effortを直接選択する。推論budgetに対して出力上限が足りない選択肢は、変更後の出力上限をメニューに明示して同時保存する。実行中・送信確認待ちには変更しない。
- 回答・ユーザー文・思考・コードは選択可能なネイティブテキストで表示し、任意の範囲をコピーできる。連続する本文の段落は1つの選択領域にする。コードブロックとの境界は選択領域が分かれるが、全文コピーは原文全体を対象にする。
- 送信したメッセージの吹き出し下にも全文コピーボタンを表示する。回答の生成中も利用でき、改行・空行・コード記号を含む送信原文をそのままコピーする。既存の部分選択コピーは残す。
- 送信文・回答・思考内のコードブロックは、言語名と専用コピーボタンを持つ枠で表示する。行頭（最大3スペースの字下げ）にある3個以上のバッククォート／チルダの囲みを認識し、同じ記号で開始以上の長さの終了行だけで閉じる。言語指定なしは「コード」と表示する。箇条書き・引用の内部構造の解析は追加しない。
- コード単独コピーには言語名・囲み記号を含めない。内部のインデント・空行・末尾の空白と改行を保持し、改行コードはLFに統一する。囲み自体の字下げ分だけ本文から除く。生成途中で終了記号が届いていなくても、受信済みのコードをコピーできる。コピー後は2秒間「コピー済み」と表示する。既存のツール入力／結果も同じ操作を使う。
- 履歴の各行のメニューと会話ヘッダーから削除できる。確認ダイアログを出し、実行中の会話は削除しない。別の会話を削除しても現在の会話・購読は維持する。
- 画面の横幅全体で右スワイプして一覧を開く。右端付近でも操作できるよう右方向24pt超で開き、縦方向の移動が大きいドラッグでは開かない。一覧は左スワイプで閉じる。文字の選択範囲を操作している間と、モデル選択・設定シート中は開かない。
- 会話行は文字だけでなく余白を含む全体を1回のタップで選べる。押している間はライト／ダークに応じたグレーを表示する。一覧を開く際は入力と文字選択のフォーカスを解除する。

## 複数チャットと切り替え

AIタブはNavigationStackへ会話画面を積まず、1つの画面の表示先を切り替える。会話ごとに下書き・モデル設定・送信確認・ストリームを保持し、遅れて返ったHTTP応答は元の会話だけに反映する。新規チャットへの切り替えも、他の会話の送信・実行が終わるまで待たない。

## 共有モード

新規チャットのトップ画面に共有モード設定を置く。ONにするとアカウント共通のモデルと1会話64K/128Kを保存し、同じモデルを2件まで並列実行する。チャット内のモデル選択は鍵表示で無効化し、contextも固定する。推論量と出力上限は会話ごとに変更できる。OFFでは会話ごとのモデル選択と順次実行へ戻る。

設定はAPIが正本。変更にはrevisionを送り、待機中を含むすべてのrunが完了したときだけ保存できる。別端末で設定が変わった場合は送信前に表示を更新し、確認後の再送を求める。ローカルに古い設定が残っても別モデルへ黙って送信しない。共有モードによって過去の会話・runのモデル名を書き換えない。
