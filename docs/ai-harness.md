# AIチャットのハーネス選択

新しい会話でHermes（汎用チャット）またはOpenCode（repoのコーディング）を選ぶ。OpenCodeは対象repoと起点ブランチを選んでから送信する。開始後はハーネス・repo・作業ブランチを固定する。モデルはハーネスと別の設定で、共有モード中はトップ画面の指定を使い、チャット内では推論量を変更できる。

OpenCodeの入力欄で「変更まで」「Draft PRまで」を選ぶ。PRのmerge/deployは対象に含めない。実行中は変更できず、次の依頼で変更できる。iOS向けのビルドはUbuntuだけでは実行できず、MacまたはCIによる検証が必要。

回答内に差分の開閉・全文コピー、PRリンク、作成時点のCI確認結果を表示する。permission/questionは会話内で回答する。許可はその操作だけに適用し、永続的な権限変更は行わない。再送しても回答を二重適用しない。生の内部状態を推測して思考として表示せず、ハーネスが提供したreasoning/toolイベントのみ表示する。

一覧への右スワイプ、ワンタップ切り替え、選択コピー、ダーク／ライト追従、生成中の別会話への移動は従来どおり。画面や通信を閉じてもPC側は実行を継続する。PCプロセスの再起動やOOMは中断として表示し、続行は次のメッセージで明示する。チャット削除は履歴だけで、PCのファイル・ブランチ・GitHub PRは消さない。

APIはv5を使用する。既存のHermes会話もそのまま表示する。初期選択はHermes・変更まで。repoが未設定ならOpenCodeを送信できず、別ハーネスへのfallbackはしない。
