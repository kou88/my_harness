# 本棚とPDF閲覧

「本」タブから直接開く。アカウントメニューからログイン・ログアウトできる。タイトル検索・ダウンロード済み絞り込み・pull-to-refreshに対応する。

一覧では表紙だけを取得し、PDFは明示した本だけダウンロードする。進捗を表示し、キャンセル・再試行できる。ダウンロード後に容量・SHA-256・PDFのページ数を確認してから保存済みにする。

保存済みPDFはオフラインで読める。PDFKitで全画面表示し、横スワイプでめくる。iPadの横長ウインドウでは左右見開き（表紙1ページ、本文2–3、4–5…）、縦長ウインドウとiPhoneでは1ページ表示に自動で切り替える。見開きでは前後移動と端タップも見開き単位になり、回転しても指定したページ番号を保持する。開いた直後は上下の操作部分を非表示にし、中央タップで表示/非表示を切り替える。画面の左端25%をタップすると前のページ、右端25%で次のページへ移動する。先頭・末尾ではそれ以上移動しない。拡大縮小・回転・ページ指定・前後移動・ページ移動バー・横スクロールのページサムネイルに対応する。読書位置はページ変更時と終了/バックグラウンド時に保存する。「端末から削除」は端末のPDFだけを削除し、原本と読書位置は保持する。

Application Support内でCognito subのSHA-256ごとに本棚を分離する。保存PDFと表紙のファイル名は書籍UUIDとPDF SHA-256の組み合わせ、ディレクトリはiCloudバックアップ対象外。ログアウト後や別アカウントでは前のアカウントの本を表示しない。オフライン時には保存済み一覧を表示していることと取得エラーを明示する。

初期版はMacから登録する。API契約・登録コマンド・R2の構成はmy_apiの `docs/pdf-library.md` を参照する。端末間の読書位置同期、OCR、アプリからのアップロードは含まない。

## ページ回転とクラウド保存（2026-10-12）

操作バーの「回転」から、表示中の任意ページを左右90度ずつ回転できる。見開きでは左右それぞれのページ番号を指定でき、他のページには適用しない。複数ページを修正してから「クラウドに保存」を押す。画面の向きだけを変える操作ではなく、PDFのページ回転情報を保存する。本文・ページ数・注釈を保持し、先頭ページから表紙を生成し直す。

変更中は未保存ページ数を表示する。保存中は編集・閉じる操作を無効にし、保存完了後は新版のPDF・サムネイルを開き直す。未保存のまま閉じる/変更を破棄する場合は確認する。通信失敗時は同じ予約ID・同じPDFで再試行し、保存完了応答が失われた場合にも二重更新しない。結果未確認の状態で破棄しても、既にクラウドへ保存済みの変更は取り消されないことを明示する。アプリ終了後の未保存編集の復元は対象外。

APIは旧SHAが一致した場合だけ新しいPDFと表紙に切り替え、別端末の先行更新を409で通知する。原本の旧オブジェクトを復旧用に保持する。上限は既存契約と同じPDF 64MiB・JPEG 1MiB。API契約と保持方針はmy_apiの `docs/pdf-library.md` が正本。

ローカルキャッシュはPDF SHAごとに分け、本棚更新時に新版と旧版を混同しない。旧TestFlightのUUIDだけの保存済みPDFは容量・SHA・ページ数を検証して移行する。読書位置は書籍IDに紐付けたまま保つ。古いローカル版は読書中の参照を壊さないため残し、「端末から削除」で同じ本の全PDF版を削除する。別端末で変更された場合は本棚を更新し、新版をダウンロードする。
