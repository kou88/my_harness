# 本棚とPDF閲覧

「本」タブから直接開く。アカウントメニューからログイン・ログアウトできる。タイトル検索・ダウンロード済み絞り込み・pull-to-refreshに対応する。

一覧では表紙だけを取得し、PDFは明示した本だけダウンロードする。進捗を表示し、キャンセル・再試行できる。ダウンロード後に容量・SHA-256・PDFのページ数を確認してから保存済みにする。

保存済みPDFはオフラインで読める。PDFKitで全画面表示し、横スワイプでめくる。iPadの横長ウインドウでは左右見開き（表紙1ページ、本文2–3、4–5…）、縦長ウインドウとiPhoneでは1ページ表示に自動で切り替える。見開きでは前後移動と端タップも見開き単位になり、回転しても指定したページ番号を保持する。開いた直後は上下の操作部分を非表示にし、中央タップで表示/非表示を切り替える。画面の左端25%をタップすると前のページ、右端25%で次のページへ移動する。先頭・末尾ではそれ以上移動しない。拡大縮小・回転・ページ指定・前後移動・ページ移動バー・横スクロールのページサムネイルに対応する。読書位置はページ変更時と終了/バックグラウンド時に保存する。「端末から削除」は端末のPDFだけを削除し、原本と読書位置は保持する。

Application Support内でCognito subのSHA-256ごとに本棚を分離する。ファイル名は書籍UUID、ディレクトリはiCloudバックアップ対象外。ログアウト後や別アカウントでは前のアカウントの本を表示しない。オフライン時には保存済み一覧を表示していることと取得エラーを明示する。

初期版はMacから登録する。API契約・登録コマンド・R2の構成はmy_apiの `docs/pdf-library.md` を参照する。端末間の読書位置同期、書き込み、OCR、アプリからのアップロードは含まない。

## 見開きとページ描画キャッシュ（2026-10-12）

通常倍率では、表示中のページと前後2ページを端末の画面解像度で先に描画して保持する。別のCGPDFDocumentを専用actorで描画し、PDFKitのページoverlayへ配置する。左右は両方の描画が完了してから表示し、未準備ページへのジャンプ時は白地の待機表示を使う。拡大中・文字選択中はPDFKitのネイティブ描画を使う。

保持する画像は通常5ページ、見開き6ページ以内。サイズ変更・回転・PDFKitの初期倍率更新時に画面解像度を再計算する。古い描画要求は破棄し、メモリ警告時は表示中の画像だけを残す。バックグラウンド移行・閲覧終了時は画像を解放する。初回表示や未キャッシュ位置へのジャンプでは高解像度描画の待ち時間が発生する。
